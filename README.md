# Minigame Portfolio

A gallery of minigames designed by UofG Game Development Club members.

## How it works

Every game will be contained in its own folder under `games/` and run in its own frame, meaning that one person's game/code won't interfere with another person's game/code. The portfolio will build its list of games automatically by reading the `game.json` of each game folder.

The foundation of this portfolio is currently in development. Documentation on how to add games will eventually be added, but it's planned to be very beginner-friendly! :)
